# TikTok สินค้าน่าไลฟ์

เว็บช่วยค้นหา กรอง และจัดอันดับสินค้าสำหรับ TikTok Shop ไทย โดยดูแรงเติบโต ความเหมาะกับการสาธิตในไลฟ์ ค่าคอมต่อออเดอร์ และระดับการแข่งขัน

## สถานะข้อมูล

รุ่นแรกใช้ข้อมูลตัวอย่างที่ติดป้ายชัดเจน ยังไม่ได้เชื่อม EchoTik หรือ FastMoss API และไม่ควรใช้ตัวเลขตัวอย่างเป็นข้อมูลตัดสินใจซื้อสื่อหรือสต็อกสินค้า

## รันโปรแกรม

```bash
npm start
```

เปิด `http://localhost:3000` และตรวจสถานะที่ `/health`
